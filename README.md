# Phenomenon Studio

A premium Next.js creative studio website with 3D WebGL hero, smooth scroll, custom cursor, and page transitions.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Three.js / @react-three/fiber
- Framer Motion
- GSAP
- Lenis smooth scroll

## Getting Started
```bash
npm install
npm run dev
```
